# Alaine Hair Studio Shopify Theme

Upload file: `alaine-hair-studio-shopify-theme.zip`

This is a Dawn-based Shopify Online Store 2.0 theme customized for Alaine Hair Studio. It includes a branded homepage, ready-unit product grid, custom wig deposit product template, cart styling, and the supplied logo asset.

## Shopify Setup

1. In Shopify admin, go to **Online Store > Themes**.
2. Choose **Add theme > Upload zip file**.
3. Upload `alaine-hair-studio-shopify-theme.zip`.
4. Create a product with handle `custom-wig-deposit`.
5. Assign that product the template `custom-wig-deposit`.
6. Set the deposit price on that product.
7. Add ready-to-wear wig products to your main collection.

## Custom Wig Fields

The custom wig deposit product collects these details as Shopify line item properties:

- Wig type
- Lace type
- Length
- Density
- Hair color
- Cap size
- Desired style
- Needed-by date
- Notes/inspiration link

These details should appear in the cart and on the Shopify order after checkout.

## Brand Direction

The theme uses the logo-inspired palette: warm caramel, honey gold, ivory, espresso, and a restrained wine accent.
